NES

Nintendo (NES) emulator — GitHub Pages demo

A single-page emulator that runs entirely in the browser using jsnes. Load a legal ROM to play. Controls and instructions below.

Tip: Use small homebrew ROMs or public-domain test ROMs while testing.
Or drag & drop a .nes file onto the page.

This demo uses the open-source jsnes project as the emulation core. The page is intentionally minimal to keep it GitHub Pages-friendly.
